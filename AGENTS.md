# Instruções para agentes

Antes de alterar o FocusEdu:

1. Leia `docs/PRODUCT.md`.
2. Leia `docs/ARCHITECTURE.md`.
3. Leia `docs/CODE_STYLE.md`.
4. Inspecione o código envolvido e o estado atual do repositório.
5. Preserve as funcionalidades e os dados existentes.
6. Limite as mudanças ao escopo solicitado.
7. Execute `npm run test`, `npm run lint`, `npm run format:check` e `npm run build` antes de concluir.
8. Atualize a documentação quando uma decisão de produto ou arquitetura mudar.
